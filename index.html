Ce qui a bougé

    Par famille

    Une application PWA se reconnaît à vite-plugin-pwa et à son déploiement Pages ; une application desktop à Electron ou Tauri. Les trois couches du socle sont nommées explicitement : le squelette est lui-même une PWA, aucun signal ne le distinguerait de ce qu'il engendre.

    Ce qui est rouge

    Dernier run de chaque workflow actif, pris sur la branche par défaut du dépôt (à défaut, le dernier run toutes branches). Les workflows réutilisables du socle sont exclus : ils n'ont pas de run propre.

    Workflows en échec : dépôt, workflow, état, étape fautive, ancienneté, lien vers le run.

    Dépôts

    Une carte par dépôt git : copie locale, pipelines, pile technique. Les versions de librairies sont celles verrouillées dans le lockfile — pas la plage déclarée.

    Aucun dépôt ne correspond à ce filtre.

    Librairies

    Versions réellement verrouillées dans les lockfiles, agrégées sur tout le parc. Seuls les paquets présents dans au moins deux dépôts sont listés : un paquet unique est une dépendance d'application, pas une librairie du parc. Le dégradé va du plus récent (foncé) au plus ancien ; au-delà de quatre versions, la queue est repliée en gris. Cliquez une ligne pour voir quel dépôt porte quelle version.

    Librairies du parc : paquet, nombre de dépôts, répartition des versions, version amont, dépôts en retard.

    Librairies dormantes

    Librairies dont la dernière version publiée a plus d'un an. La date de publication seule ne dit pas grand-chose : une bibliothèque peut être stable et finie, ou simplement abandonnée. Ce tableau montre donc deux dates — la dernière version parue au registre, et le dernier commit reçu par le dépôt amont. Quand les deux se sont tues, la question d'un remplacement se pose ; quand seul le registre se tait, c'est une version qui manque, pas un projet mort.

    Librairies sans publication depuis plus d’un an : paquet, dépôts, dernière version, âge, dépôt amont, dernier commit, lecture.

    Aucune librairie du parc n'est restée plus d'un an sans publication.

    Matrice des écarts

    La section précédente répond « qui porte quelle version » paquet par paquet ; celle-ci les met côte à côte. Une ligne est un dépôt, une colonne un paquet, une cellule la version qu'il verrouille. La couleur ne dit pas « vieux » dans l'absolu mais l'écart à la version la plus récente du parc — la seule sur laquelle on peut agir, puisqu'un autre dépôt la tient déjà. Par défaut, seuls les paquets réellement éclatés sont montrés ; les colonnes s'ajoutent et se retirent une à une.
